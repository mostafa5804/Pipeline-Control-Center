# Pipeline Control Center 1.0.0

First public generic release.

The application starts with no predefined route or project data. Users can import one or more KML/KMZ routes, preview and name them, then manage pipeline progress fronts, features/obstacles, photos, timeline, sequence/gap analysis, meeting mode and a read-only single-file Presentation Viewer.
